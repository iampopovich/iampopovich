# Hi, I'm Alex Popov

QA / SDET engineer. I write test automation in Python, C# and Java, and build the tools around it: MCP servers that let AI assistants work with test management systems, CI pipelines, scrapers and browser automation. In my spare time I make Android apps and small open-source games, and keep a family of Linux snap packages up to date.

## Open source I contribute to

- [Selenium](https://github.com/SeleniumHQ/selenium): 70+ merged pull requests, fixes and features across the language bindings.
- [allure-csharp](https://github.com/allure-framework/allure-csharp): Allure adapters for .NET test frameworks.
- [QA_bible](https://github.com/VladislavEremeev/QA_bible): a Russian-language QA knowledge base; I wrote the AI-in-testing section.
